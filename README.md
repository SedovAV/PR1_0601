### Цель работы

* Научиться генерировать синтетические данные для задач регрессии.
* Реализовать модель линейной регрессии с использованием библиотеки scikit-learn.
* Научиться разделять выборку на обучающую и тестовую.
* Изучить явление переобучения (overfitting) на примере полиномиальной регрессии.
* Освоить методы оценки качества модели (MSE, R²) и визуализации результатов.

### СПРАВКА

* Полиномиальная регрессия -метод анализа данных и машинного обучения, который описывает нелинейную связь между независимой переменной x и зависимой переменной y с помощью полинома (многочлена)
* Полином - математическое выражение, которое состоит из суммы или разности простых выражений (одночленов), где переменные возведены в целые неотрицательные степени
